# Recurring research

Use this reference when revisiting an instrument or maintaining a thesis. Match the
depth to the question. A routine daily update usually needs the changes and their
implications; an earnings release may warrant a fuller review.

## Choose the comparison

Read the previous completed report for the same instrument, research mode, and
timeframe. Completion means the run finished; check its verification status before
reusing its claims. Name the report and its original date. If the latest run failed
or covered a different question, explain which earlier baseline you used. Keep
failed and partial runs intact. If no comparable report exists, establish a baseline
without inventing a change.

Separate new disclosures or other sourced facts from market price changes and from
changes in interpretation. Re-fetching an old filing does not make it new. A price
move can change valuation without changing business performance. If nothing material
changed, say so and keep the update short.

## Check the claims that drive the conclusion

For material figures, use a compact table or equivalent structured record:

| Claim | Value and unit/currency | Fiscal period or market timestamp | Source and publication date | Verification |
|---|---|---|---|---|
| Metric or event | Reported value, estimate, or unknown | Period start/end or timestamp with timezone | Direct document/data link | Verified, unverified, or conflicting; method or unresolved difference |

Keep retrieval time separate from the observation's effective time. Identify reported
results, management guidance, outside consensus, and your own assumptions. A model
report is not independent confirmation of the data it received.

Check quarter versus year-to-date periods before computing growth, margins, or free
cash flow. Derive a standalone quarter from cumulative figures only when fiscal
boundaries, units, accounting definitions, and restatements are compatible; show the
subtraction. A period-end date alone cannot establish the duration. Leave the result
unknown when the source omits needed period information.

For technical comparisons, keep interval, adjusted/unadjusted prices, lookback, and
session boundaries consistent. Compare the latest completed trading session rather
than treating a weekend or an unfinished bar as a new full session.

## Test the thesis

State the thesis as a claim that evidence could disprove. Track each relevant pillar
against its earlier expectation, the new evidence, and whether it strengthened,
weakened, or remained unchanged. Give disconfirming evidence the same attention as
supporting evidence. Describe what future observation would change the assessment.
Keep a model's suggested action separate from the user's confirmed decision.

A model score, weighted indicator score, or bull/bear vote is not a calibrated
probability. Describe what a score measures. Report a probability only with a stated
estimation method and supporting evaluation; label assumed scenario weights as
assumptions. Agreement among models using the same source is not independent evidence.

## Save the update

A useful short report contains the answer, changes since the named baseline,
supporting evidence, thesis implications, and remaining uncertainties. Add sections
only when they help answer the question. Personal portfolio fit remains a separate
step using dated account data and the user's limits.

Link raw engine output and its receipt or manifest. Record provider/model, requested
and completed modes, failures, and verification status. Include actual reported token
usage or cost when available, distinguish estimates, and leave unavailable cost
unknown. Preserve the original run timestamps and cite any corrections separately.
